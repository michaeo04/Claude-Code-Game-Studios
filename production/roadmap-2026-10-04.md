## 4. Rules that govern the work (so a new session does not have to rediscover them)

- **Where work lives**: commit and push to `dev` only. Merging into `main`, tags, force pushes, deleting remote branches, repository settings and visibility need your explicit approval each time (`.claude/docs/git-workflow.md`, CLAUDE.md).
- **Test-first, proof before Complete**: a story is `Complete` only when every acceptance criterion is proven by a passing test or recorded evidence; otherwise it stays `Ready` with the gap written down. Never skip or weaken a test; never edit `tools/ci/lint_rules.json` to turn a lint green (a story that needs a new rule adds it with a passing and a failing fixture).
- **The gate**: `export GODOT="C:/Users/candl/tools/godot-4.7.2/Godot_v4.7.2-stable_win64_console.exe"; python tools/ci/run_ci.py --only all`. A raw Godot run exits 0 even on a parse error or with no tests; only the `run_ci.py` verdict counts.
- **Architecture rules** are in the control manifest (649 rules, version 2026-10-03): one `_process` in `GameRoot`, no autoloads, injected clock, pure `RefCounted` cores with no engine calls, static typing, data-driven config, no raw `s` in a `Vector3`, no physics nodes, no `CONNECT_DEFERRED`. ADR changes bump the manifest version.
- **Review budget**: you capped independent reviews at three; they were spent on the architecture (run 5, two technical-director passes). New reviews are on request, or the single code-review pass proposed above.
- **Engine knowledge**: Godot 4.7.2 is newer than the model's knowledge; check `docs/engine-reference/godot/` and prove behaviour with a test or a spike before relying on an API.
- **Verification obligation**: never record a sign-off or ratification without verifying it in `production/session-logs/agent-audit.log`.
- **Language**: replies to you in Vietnamese; repository files in English.
