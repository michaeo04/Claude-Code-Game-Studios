# Ball Movement — Device/Playtest Evidence

Evidence files for the Ball Movement GDD's Device and playtest checks
(`design/gdd/ball-movement.md`, BM-1a, BM-1b, BM-2 through BM-6) land here,
named `bm-N.md` (device, build, date, raw log, result).

Created ahead of the on-device spike (producer condition, 2026-09-22 `/design-review`
pass 3) so evidence has a home from day one instead of being created ad hoc when the
first result comes in.

BM-1a (software latency) can be run and logged here the first day any single Android
device is available — it does not need to wait for the BM-1b jig rig or the full
device set (≥2 Android makers + 1 iPhone).
